# ssfps5tester

Designed for SSF staff to test the PS5 controllers in the games room. Includes live inputs, stick precision, guided hardware checks and controller information.

## Use

Connect a controller by USB (Recommended to test all funcionality) or Bluetooth and press a button. For detailed PlayStation checks, use Chrome or Edge and select **Connect PlayStation**.


PS5 Remote controlling feature is still underdevolpment is not fully functional yet.
